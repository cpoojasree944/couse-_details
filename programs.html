A CLEAR PATH FORWARD

Inside the curriculum

Every module pairs essential concepts with practical skills to help you keep moving forward.

01
DATA & INSIGHTS

Data Analytics

6 months · 5 modules
Explore the syllabus
  1. Introduction to Data AnalyticsGet to know the analytics workflow, data types, and how organizations use information to make decisions.
  2. Python Programming for Data AnalysisLearn Python fundamentals and use code to inspect, organize, and analyze datasets.
  3. SQL and Database ManagementQuery relational data, combine tables, and understand the foundations of database management.
  4. Data Cleaning and ProcessingPrepare reliable datasets by handling missing values, inconsistencies, and common data issues.
  5. Data Visualization using Power BITurn findings into clear visuals and build dashboards that communicate useful insights.
02
EMERGING TECHNOLOGY

Generative AI

4 months · 5 modules
Explore the syllabus
  1. Introduction to Artificial IntelligenceExplore foundational AI concepts, common applications, capabilities, and responsible use.
  2. Python for AIPractice the Python fundamentals used to work with AI tools, data, and application logic.
  3. Large Language ModelsUnderstand how language models work, what they can do, and where their limitations lie.
  4. Prompt EngineeringWrite and refine instructions to guide AI models toward useful, consistent responses.
  5. Building AI ApplicationsBring concepts together to create useful applications powered by modern AI tools.
03
SOFTWARE DEVELOPMENT

Full Stack Development

6 months · 6 modules
Explore the syllabus
  1. HTML FundamentalsStructure accessible web pages using semantic HTML and well-organized document markup.
  2. CSS StylingStyle responsive interfaces with layout systems, typography, color, and reusable CSS.
  3. JavaScript ProgrammingBuild a foundation in variables, functions, data structures, and browser-based programming.
  4. React DevelopmentOrganize user interfaces into reusable components and learn the core ideas behind React.
  5. Backend DevelopmentExplore server-side application concepts, routes, and communication between services.
  6. Database and DeploymentUnderstand data persistence and the steps involved in preparing an application for release.
04
INTELLIGENT SYSTEMS

Machine Learning

5 months · 5 modules
Explore the syllabus
  1. Introduction to Machine LearningLearn the core ideas behind machine learning and how models learn patterns from data.
  2. Python for Machine LearningUse Python and common data libraries to prepare inputs for a machine learning workflow.
  3. Supervised LearningExplore models that learn from labeled examples to classify outcomes and make predictions.
  4. Unsupervised LearningDiscover approaches for finding structure and useful groupings in unlabeled data.
  5. Model EvaluationAssess model performance, interpret evaluation measures, and understand trade-offs.

NEED A LITTLE CLARITY?

Frequently asked questions.

Here are a few answers to help you choose the learning path that feels right for you.

Still curious? Talk to us ↗
01Are these courses suitable for beginners?

Generative AI and Full Stack Development are marked beginner level. Data Analytics is intermediate, and Machine Learning is advanced. Check each course overview to find the best starting point for your experience.

02How long does each course take?

Data Analytics and Full Stack Development are 6 months each, Generative AI is 4 months, and Machine Learning is 5 months.

03Will students work on practical projects?

Yes. Each program includes practical projects designed to help you apply key concepts and develop work you can present in a portfolio.

04What technologies will students learn?

Technology varies by program and includes Python, SQL, Excel, Power BI, AI tools, HTML, CSS, JavaScript, React, Node.js, NumPy, Pandas, Scikit-learn, and TensorFlow.

05What career opportunities are available?

Potential paths include data analyst, AI developer, full stack developer, machine learning engineer, business analyst, software developer, and cybersecurity analyst. Specific opportunities depend on your skills and experience.
